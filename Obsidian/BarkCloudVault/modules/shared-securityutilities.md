# Shared — SecurityUtilities

Parent: [[index]]

## Назначение

Общие утилиты безопасности — однофайловая библиотека.

## Расположение

`Shared/BarkCloud.Shared.SecurityUtilities/`

## Файлы

- `SecurityUtilities.cs` — статические методы (хеширование, генерация случайных значений, сравнение в постоянное время — подробности см. в коде)

## Зависимости

- Используется: вероятно `Identity` (для паролей/токенов) и `Files` (для хешей файлов). Уточняй по факту использования при правках.
