# BarkCloud — бриф для продуктового сайта

> Документ для агента-верстальщика. Цель: сверстать маркетинговый сайт продукта BarkCloud.
> Источник данных: Obsidian Vault проекта (`Obsidian/BarkCloudVault/`). Дата: 2026-05-31.

---

## 1. О продукте

**BarkCloud** — это **self-hosted облачное хранилище и медиатека** с нативными клиентами под все платформы. Пользователь поднимает свой сервер и получает «свой Google Photos / iCloud»: фото и видео, файлы, альбомы, резервные копии — под полным личным контролем, без привязки к чужому облаку.

**Ключевые ценности (для главного экрана сайта):**
- 🔒 **Self-hosted, ваши данные — у вас.** Свой сервер, своё хранилище, свои правила.
- 📱 **Нативные клиенты везде:** iOS, Android, Web, Windows (виртуальный диск).
- 🖼 **Медиатека:** галерея фото/видео, альбомы, метаданные EXIF/GPS, превью.
- ☁️ **Автоматические бэкапы:** фоновая загрузка фото/видео с телефона в облако.
- 📂 **Полноценный файловый менеджер:** папки, перемещение, корзина, избранное, публичные ссылки.
- 🛡 **Безопасность:** 2FA (TOTP + email-OTP), управление устройствами и сессиями, блокировка приложения по Face ID/PIN.

**Целевая аудитория:** энтузиасты self-hosting, приватность-ориентированные пользователи, малые команды, которым нужна альтернатива публичным облакам.

## 2. Платформы («проекты») и их статус

| Платформа | Технологии | Статус | Краткое позиционирование |
|-----------|-----------|--------|--------------------------|
| **iOS** | SwiftUI, Swift 5, iOS 18+ | ✅ Реализовано | Самый полный клиент: бэкап, фоновая загрузка, Live Activity |
| **Android** | Kotlin, Jetpack Compose, Material 3 | ✅ Реализовано | Полнофункциональный клиент, Android 11+ (SDK 30) |
| **Web** | React 18 + TypeScript, Vite | ✅ Реализовано | Доступ из браузера, публичные ссылки, управление аккаунтом |
| **Windows Drive** | .NET, Dokany, WPF | 🟡 PoC (фазы 1–5) | Облако как виртуальный диск `X:` в Проводнике |
| **Backend** | .NET 10, gRPC, PostgreSQL, MinIO, RabbitMQ | ✅ Реализовано | Микросервисы: Identity, Users, Files, Notification, Configuration |

> Для сайта: iOS / Android / Web подаём как готовые продукты; Windows Drive — как «скоро»/beta.

## 3. Возможности по платформам (для блоков «Features»)

### 3.1 iOS (самый полный набор)
- Регистрация и вход с OTP/2FA; мастер настройки адреса своего сервера при первом запуске.
- 5 разделов: **Галерея** (медиатека устройства), **Файлы** (локальные + облачные), **Альбомы**, **Корзина**, **Настройки**.
- Облачные медиа: cursor-пагинация, просмотр в QuickLook (Live Text, Visual Look Up).
- **Альбомы:** создание, редактирование, обложка, добавление/удаление элементов, фильтр фото/видео.
- **Файловый менеджер облака:** папки CRUD, хлебные крошки, перемещение, загрузка документов.
- **Резервное копирование (Backup):** автозагрузка фото/видео, прогресс скана, папка «Недавно загруженные», «Освободить место», кэш «уже в облаке».
- **Фоновая загрузка:** переживает сворачивание/перезапуск, Live Activity (Lock Screen + Dynamic Island), Share Extension, retry при сбоях.
- **Безопасность:** блокировка приложения Face ID/Touch ID + PIN, Keychain для токенов.
- Свойства файла с метаданными (EXIF/GPS/камера/видео/документ), оффлайн-кэш, мультивыбор, фирменный pull-to-refresh (анимированная лиса).

### 3.2 Android
- Регистрация и вход с OTP/2FA.
- 5 табов: **Галерея**, **Файлы** (локальный браузер), **Альбомы**, **Корзина**, **Настройки**.
- Облачное хранилище медиа: загрузка из галереи, просмотр с пагинацией, бейдж «уже в облаке».
- Альбомы (CRUD + управление элементами), файловый браузер облака (папки/файлы CRUD, перемещение, загрузка документов).
- Корзина (восстановление, окончательное удаление, очистка).
- Профиль и настройки: аватар, приватность, устройства, выход.
- UI: Material 3 Expressive.

### 3.3 Web (браузер)
- Аутентификация: логин/регистрация/восстановление пароля по email-коду, 2FA (TOTP + email-OTP).
- **Галерея** (Фото/Видео): бесконечная прокрутка, drag&drop загрузка, лайтбокс с зумом, мультивыбор.
- **Альбомы:** просмотр/создание/редактирование/удаление, обложка, поиск.
- **Файловый менеджер:** иерархия папок, CRUD, загрузка фото/видео/документов, контекстное меню.
- **Корзина:** восстановление, окончательное удаление, очистка.
- **Избранное.**
- **Публичные ссылки:** постоянные ссылки на файлы, счётчик переходов, отзыв, анонимный доступ `/s/{token}`.
- Свойства файла с метаданными, поиск по имени.
- Настройки аккаунта: профиль, аватар, email, приватность, устройства/сессии, хранилище (квота), смена пароля, 2FA, удаление аккаунта, тема (light/dark/auto).

### 3.4 Windows Drive (PoC / beta)
- Монтирование облака как буквы диска (`X:`) в Проводнике.
- Просмотр и чтение файлов по запросу (поблочно, HTTP Range — большие файлы не качаются целиком).
- Запись, создание/удаление/переименование/перемещение папок и файлов.
- Локальный кэш на диске, автомонтирование при восстановленной сессии, иконка в трее, дашборд с прогрессом хранилища.

### 3.5 Backend (для блока «как это устроено» / для тех-аудитории)
- **Identity:** регистрация с подтверждением по email, логин, OTP/2FA, refresh-токены, сброс пароля, сессии.
- **Users:** профиль (имя/юзернейм/bio), аватар, приватность, устройства, поиск пользователей, удаление аккаунта, push-токены.
- **Files:** загрузка с дедупликацией по SHA-256, галерея, иерархия папок, альбомы, корзина (soft-delete 14 дней), избранное, публичные ссылки, извлечение метаданных, превью (128/512/1024 + кадр видео), квота.
- **Notification:** email с кодами и уведомлениями (вход, смена пароля, смена 2FA).
- **Configuration:** централизованная конфигурация микросервисов.
- Инфраструктура: PostgreSQL, MinIO (S3-совместимое хранилище), RabbitMQ, Serilog→Seq, nginx (TLS), Docker Compose.

## 5. Требования к сайту (для верстальщика)

**Тип сайта:** одностраничный лендинг продукта (возможно + страница загрузок и страница «возможности»).

**Рекомендуемая структура:**
1. **Hero:** название, слоган про self-hosted облако, кнопки «Скачать» / «Документация», скриншот/мокап приложения.
2. **Ключевые преимущества** (3–6 карточек): приватность/self-hosted, мультиплатформенность, автобэкап, медиатека, безопасность, файловый менеджер.
3. **Платформы:** карточки iOS / Android / Web / Windows со статусами и ссылками на скачивание.
4. **Возможности в деталях:** скриншоты + описания (галерея, альбомы, бэкап, файлы, публичные ссылки).
5. **Сравнительная таблица** фич по платформам (раздел 4).
6. **«Как это устроено»** (для тех-аудитории): схема микросервисов, стек, «разверни за 5 минут в Docker».
7. **CTA / футер:** ссылки на репозиторий, документацию, контакты.

**Бренд / визуал:**
- Маскот/тема — лиса (в iOS фирменный pull-to-refresh с анимированной лисой). Можно обыграть «Bark» (лай) + облако.
- Палитра: Material 3 (клиенты используют M3 Expressive). Поддержка light/dark уместна.
- Bundle/namespace: `com.barkfluff.BarkCloud`, домен в коде — `cloud.barkfluff.com`.

**Тон:** продукт для технически грамотной аудитории, ценящей приватность. Акцент — «контроль над своими данными» + «не хуже больших облаков по удобству».

**Важные оговорки (не обещать лишнего):**
- Windows Drive — PoC/beta (read-write базово, нет инсталлятора, копирование внутри диска ограничено).
- Шеринг между пользователями («Общие файлы») пока не реализован.
- Self-signed TLS в текущей сборке (упоминать как «self-hosted, свой сертификат»).
