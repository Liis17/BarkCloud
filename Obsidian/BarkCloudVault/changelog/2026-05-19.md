# 2026-05-19 — iOS клиент: полный паритет с Android (PR 1–6)

Parent: [[index]]

Реализован iOS-клиент полностью по плану `~/.claude/plans/mellow-waddling-biscuit.md`. Шесть последовательных PR-кусков, итоговый build чистый.

## [Ios/BarkCloud/BarkCloud.xcodeproj/project.pbxproj] — PR 1: setup

- Что изменилось: `IPHONEOS_DEPLOYMENT_TARGET` 26.4 → 18.0; `SUPPORTED_PLATFORMS` сужен до `iphoneos iphonesimulator`; убраны `MACOSX_DEPLOYMENT_TARGET`, `XROS_DEPLOYMENT_TARGET`, macOS-runpath; `TARGETED_DEVICE_FAMILY` = `1,2`; `SDKROOT = iphoneos`; `knownRegions` += `ru`; `ENABLE_USER_SCRIPT_SANDBOXING = NO`; `SWIFT_DEFAULT_ACTOR_ISOLATION` удалён (мешал Sendable у protobuf-типов); подключены 4 SPM-пакета (grpc-swift-2 2.4.1, grpc-swift-nio-transport 2.7.0, grpc-swift-protobuf 2.4.0, swift-protobuf 1.38.0); добавлена Run-Script фаза «Sync Shared Proto» перед «Compile Sources».
- Почему: основа проекта под iOS 18, grpc-swift v2 и автогенерацию proto. Build-tool plugin `GRPCProtobufGenerator` не цепляется к app-target через pbxproj — используется fallback с `protoc` напрямую через Homebrew (`protoc`, `protoc-gen-swift`, `protoc-gen-grpc-swift-2`).
- Связанные файлы: [[modules/ios-app]]

## [Ios/BarkCloud/sync_proto.sh] — синхронизация и кодоген proto

- Что изменилось: скрипт синхронизирует `Shared/BarkCloud.Proto/{identity,users,files,shared}_api.proto` → `Ios/BarkCloud/Proto/` (вне `BarkCloud/`, чтобы filesystem-synced group не пыталась их компилировать) и вызывает `protoc` с двумя плагинами; сгенерённые `.pb.swift` и `.grpc.swift` оседают в `BarkCloud/Generated/Proto/` и автоматически попадают в target.
- Почему: build-tool plugin для app target не работает через pbxproj — fallback с инсталлированными через brew генераторами надёжнее.

## [Ios/BarkCloud/BarkCloud/Networking] — PR 2: gRPC infrastructure

- Что изменилось: `Base64Header`, `AuthErrorCodes` (UUID-ы InvalidCredentials / OtpRequired / InvalidRefreshToken), `GrpcError` (extension на `RPCError` для `x-error-code` трейлера); 5 интерсепторов (`AuthInterceptor` с tokenProvider closure, `XDeviceInterceptor` с identifierForVendor + hw.machine model, `XOsInterceptor` с "iOS X.Y", `XAppInterceptor` с CFBundleShortVersionString, `XIpInterceptor` с getifaddrs); `GrpcManager` (actor с lazy `GRPCClient<HTTP2ClientTransport.Posix>`, TLS с `.noVerification` для dev на `localhost:5001`, `runConnections()` в отдельной Task).
- Важно: Swift 6.2 `NonisolatedNonsendingByDefault` потребовал `@concurrent` на `func intercept` и параметре `next` — без этого тип не соответствует `ClientInterceptor` протоколу.
- Связанные файлы: [[api/identity-api]], [[modules/shared-auth]]
