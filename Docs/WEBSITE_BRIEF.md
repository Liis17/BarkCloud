# BarkCloud — описание проекта

> Материал для агента-верстальщика сайта продукта.
> Источник: Obsidian Vault проекта (`Obsidian/BarkCloudVault/`). Дата: 2026-05-31.

## О продукте

**BarkCloud** — **self-hosted облачное хранилище и медиатека** с нативными клиентами под все платформы. Пользователь поднимает собственный сервер и получает «свой Google Photos / iCloud»: фото и видео, файлы, альбомы, резервные копии — под полным личным контролем, без привязки к чужому облаку.

**Ключевые ценности:**
- 🔒 Self-hosted — свой сервер, своё хранилище, свои правила.
- 📱 Нативные клиенты: iOS, Android, Web, Windows.
- 🖼 Медиатека: галерея фото/видео, альбомы, метаданные EXIF/GPS, превью.
- ☁️ Автоматические бэкапы фото/видео с телефона.
- 📂 Файловый менеджер: папки, перемещение, корзина, избранное, публичные ссылки.
- 🛡 Безопасность: 2FA (TOTP + email-OTP), управление устройствами и сессиями, блокировка по Face ID/PIN.

**Целевая аудитория:** энтузиасты self-hosting, приватность-ориентированные пользователи, малые команды, которым нужна альтернатива публичным облакам.

## Платформы

| Платформа | Технологии | Статус | Позиционирование |
|-----------|-----------|--------|------------------|
| **iOS** | SwiftUI, Swift 5, iOS 18+ | ✅ Реализовано | Самый полный клиент: бэкап, фоновая загрузка, Live Activity |
| **Android** | Kotlin, Jetpack Compose, Material 3 | ✅ Реализовано | Полнофункциональный клиент, Android 11+ |
| **Web** | React 18 + TypeScript, Vite | ✅ Реализовано | Доступ из браузера, публичные ссылки |
| **Windows Drive** | .NET, Dokany, WPF | 🟡 PoC / beta | Облако как виртуальный диск `X:` в Проводнике |
| **Backend** | .NET 10, gRPC, PostgreSQL, MinIO, RabbitMQ | ✅ Реализовано | Микросервисы: Identity, Users, Files, Notification, Configuration |

## Возможности по платформам

### iOS
- Вход с OTP/2FA; мастер настройки адреса своего сервера при первом запуске.
- 5 разделов: Галерея, Файлы (локальные + облачные), Альбомы, Корзина, Настройки.
- Облачные медиа: пагинация, просмотр в QuickLook (Live Text, Visual Look Up).
- Альбомы: создание, редактирование, обложка, элементы, фильтр фото/видео.
- Файловый менеджер облака: папки CRUD, хлебные крошки, перемещение, загрузка документов.
- Резервное копирование: автозагрузка фото/видео, прогресс скана, «Освободить место», кэш «уже в облаке».
- Фоновая загрузка: переживает сворачивание/перезапуск, Live Activity (Lock Screen + Dynamic Island), Share Extension.
- Безопасность: блокировка приложения Face ID/Touch ID + PIN.
- Свойства файла с метаданными (EXIF/GPS/камера/видео), оффлайн-кэш, мультивыбор, фирменный pull-to-refresh с анимированной лисой.

### Android
- Вход с OTP/2FA.
- 5 табов: Галерея, Файлы, Альбомы, Корзина, Настройки.
- Облачное хранилище медиа: загрузка из галереи, просмотр с пагинацией, бейдж «уже в облаке».
- Альбомы (CRUD + управление элементами), файловый браузер облака, корзина.
- Профиль и настройки: аватар, приватность, устройства.
- UI: Material 3 Expressive.

### Web
- Аутентификация: логин/регистрация/восстановление пароля по email-коду, 2FA (TOTP + email-OTP).
- Галерея (Фото/Видео): бесконечная прокрутка, drag&drop, лайтбокс с зумом, мультивыбор.
- Альбомы: просмотр/создание/редактирование/удаление, обложка, поиск.
- Файловый менеджер: иерархия папок, CRUD, загрузка фото/видео/документов.
- Корзина, Избранное.
- Публичные ссылки: постоянные ссылки на файлы, счётчик переходов, отзыв, анонимный доступ `/s/{token}`.
- Свойства файла с метаданными, поиск по имени.
- Настройки аккаунта: профиль, аватар, приватность, устройства/сессии, хранилище (квота), смена пароля, 2FA, удаление аккаунта, тема.

### Windows Drive (PoC / beta)
- Монтирование облака как буквы диска (`X:`) в Проводнике.
- Чтение файлов по запросу (поблочно, HTTP Range).
- Запись, создание/удаление/переименование/перемещение папок и файлов.
- Локальный кэш, автомонтирование, иконка в трее, дашборд с прогрессом хранилища.

### Backend
- **Identity:** регистрация с подтверждением по email, логин, OTP/2FA, refresh-токены, сброс пароля, сессии.
- **Users:** профиль, аватар, приватность, устройства, поиск пользователей, удаление аккаунта.
- **Files:** загрузка с дедупликацией по SHA-256, галерея, иерархия папок, альбомы, корзина (soft-delete 14 дней), избранное, публичные ссылки, метаданные, превью, квота.
- **Notification:** email с кодами и уведомлениями.
- **Configuration:** централизованная конфигурация микросервисов.
- Инфраструктура: PostgreSQL, MinIO (S3), RabbitMQ, Serilog→Seq, nginx (TLS), Docker Compose.

## Бренд и оговорки

- Маскот/тема — **лиса** (в iOS фирменный pull-to-refresh с анимированной лисой); обыгрывается «Bark» (лай) + облако.
- Палитра: Material 3, поддержка light/dark. Namespace `com.barkfluff.BarkCloud`, домен `cloud.barkfluff.com`.
- **Не обещать лишнего:** Windows Drive — PoC/beta (нет инсталлятора); шеринг между пользователями («Общие файлы») пока не реализован; self-signed TLS.
